# Budget Tracker Mobile App

## Overview

Budget Tracker is an Android application designed to help users manage their personal finances by tracking income, expenses, and account balances. The app provides a simple and user friendly interface that makes it easy to record transactions and monitor spending habits.

## Features

### Dashboard
- Displays current balance
- Displays most recent transactions
- Contains navigation buttons

### Add Income
- Enter an income source
- Record income amount
- Update account balance

### Add Expense
- Enter an expense description
- Record expense amount
- Update account balance

### Transaction History
- View previously entered transactions
- Displays transaction details and amounts

### Spending Breakdown
- View spending organized by category
- Monitor spending patterns and habits

## Technologies Used

- Kotlin
- Java
- XML

## Installation

1. Download or clone the project.
2. Open the project in Android Studio.
3. Allow Gradle to sync.
4. Run the application on an Android emulator or Android device.

## Usage

1. Launch the application.
2. Review financial information on the Dashboard.
3. Select **Add Income** to record earnings.
4. Select **Add Expense** to record spending.
5. View transaction history to monitor activity.
6. Use the Spending Breakdown page to analyze expenses.

## Target Audience

This application is designed for young adults, college students, and anyone looking for a simple way to track income and expenses while developing better budgeting habits.
